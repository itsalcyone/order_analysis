# 📊 Order Analysis

Приложение для пакетной обработки CSV-файлов с данными о заказах и формирования сводного отчета по ключевым метрикам продаж.

## Описание проекта

Проект предназначен для автоматизации анализа данных о заказах. Программа считывает все CSV-файлы из указанной директории, проверяет корректность их структуры, рассчитывает основные показатели по завершенным заказам и формирует единый отчет.

Во время обработки выполняется валидация входных данных. Некорректные файлы не прерывают выполнение программы — информация об ошибках записывается в журнал, после чего обработка продолжается для остальных файлов.

## Основные возможности

* пакетная обработка всех CSV-файлов из папки;
* проверка структуры входных данных;
* проверка наличия обязательных столбцов;
* проверка типов данных;
* проверка формата полей с датой;
* фильтрация заказов по заданному статусу;
* расчет ключевых бизнес-метрик;
* сохранение итогового отчета в CSV;
* логирование ошибок обработки.

## Рассчитываемые метрики

Для каждого файла вычисляются:

* **Общая выручка** (`total_revenue`);
* **Средний чек** (`average_bill`);
* **Количество заказов** (`orders_number`).

Расчет производится только для заказов с указанным статусом (значение задается в `config.py`).

## Запуск
Установить зависимости:

```bash
pip install -r requirements.txt
```

Выполнить команду запуска

```bash
python run.py
```

После запуска приложение:

1. считывает все CSV-файлы из папки `data`;
2. выполняет проверку структуры данных;
3. рассчитывает необходимые показатели;
4. сохраняет сводный отчет в папку `reports`;
5. записывает информацию об ошибках в `logs/error.log`.

## Входные данные

Каждый CSV-файл должен содержать структуру, определенную в `config.py`.

Во время обработки выполняются проверки:

* наличие обязательных столбцов;
* соответствие типов данных;
* корректность формата дат;
* отсутствие пустых файлов.

Если файл не проходит проверку, он пропускается, а причина фиксируется в журнале ошибок.

## Выходные данные

В результате работы создается файл:

```text
reports/
└── summary_report.csv
```

Он содержит агрегированные показатели по каждому успешно обработанному файлу:

| Поле          | Описание                |
| ------------- | ----------------------- |
| file_name     | Имя обработанного файла |
| total_revenue | Общая выручка           |
| average_bill  | Средний чек             |
| orders_number | Количество заказов      |

---

## Обработка ошибок

Проект предусматривает обработку наиболее распространенных ошибок:

* пустой CSV-файл;
* отсутствие обязательных колонок;
* неверные типы данных;
* некорректный формат даты;
* неизвестные ошибки во время обработки.

Все ошибки записываются в файл журнала, что позволяет продолжить обработку остальных файлов без остановки программы.

## Архитектура

Основная логика реализована в классе `OrderAnalyzer`.

Класс отвечает за:

* чтение файлов;
* валидацию структуры данных;
* фильтрацию заказов;
* вычисление бизнес-метрик;
* пакетную обработку директории;
* формирование итогового отчета;
* сохранение результатов.
